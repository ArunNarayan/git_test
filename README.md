# Pacman Game

A simple Pacman clone built with [Pygame](https://www.pygame.org/). Use the arrow keys to move Pacman around the maze and collect dots while avoiding the ghost.

## Requirements
* Python 3.11+
* Pygame 2.6+

Install dependencies with:

```bash
pip install pygame
```

## Running the Game

```bash
python3 pacman.py
```

The game window will open. Move Pacman using the arrow keys. Your score is printed when the game ends.
